「$ARGUMENTS」ジャンルの週次リサーチサイクルを実行して。

実行前に `~/Brain/YouTube/weekly/` ディレクトリが存在しなければ作成すること。
本日の日付を取得し、保存ファイル名 `[YYYY-MM-DD]_週次リサーチ.md` を確定してから開始する。

---

## Phase 1：アルゴリズム推薦分析（30分相当）

Brave Searchで以下の3クエリを順番に検索する：

1. `"$ARGUMENTS" 急上昇 YouTube 2026`
2. `"$ARGUMENTS" AI 動画 バズ 再生数`
3. `"$ARGUMENTS" shorts viral 2026`

検索結果から動画URLを最大3本抽出し、以下の基準で外れ値候補を判定する：

```
外れ値候補の条件（いずれかを満たすもの）：
  - タイトル・サムネイルから明らかに高CTRが見込まれる構成
  - 公開から短期間で高再生数（概要欄・コメントから推定）
  - サムネイルに「驚き/喜び/不安/共感」の感情が明確に出ている
```

抽出した3本を一覧で出力する：
```
外れ値候補：
  1. [タイトル] / [URL] / [外れ値候補の根拠]
  2. [タイトル] / [URL] / [外れ値候補の根拠]
  3. [タイトル] / [URL] / [外れ値候補の根拠]
```

---

## Phase 2：サムネイル感情分析（30分相当）

Phase 1で特定した3本をFirecrawlでスクレイプする。
各動画のページから以下を抽出・分析する：

```
動画1：[タイトル]
  サムネイル主感情：[驚き/喜び/不安/共感]
  感情を生む要素：
    - 要素1：[例：目が大きく開いた動物の表情]
    - 要素2：[例：高彩度の背景色]
    - 要素3：[例：テキストなし（映像のみ）]
  クリック衝動の仮説：[なぜこのサムネイルはクリックされるか]
```

3本分の分析を完了したら、**共通要素を1段落で要約する：**
```
今週のサムネイルトレンド：
  [3本に共通して見られた感情・構成要素・スタイルを記述]
```

---

## Phase 3：フック感情強度分析（30分相当）

yt-analysisで Phase 1 の3本を分析する。
各動画について冒頭30秒に絞って以下を記録する：

```
動画1：[タイトル]
  冒頭3秒の描写：[映像・音声・テキストの具体的内容]
  感情タイプ：[驚き/不安/喜び/共感 など]
  感情強度：[1〜5]（5が最高）
  フックタイプ：[8パターンから1つ選択]
  視聴者が止まった理由：[具体的に]
  3秒保持率の推定：[高/中/低 + 根拠]
```

3本の分析完了後、**今週のフック強度ランキングを出力する：**
```
今週のフック強度ランキング：
  1位：[タイトル] - 強度5 - [理由]
  2位：[タイトル] - 強度__ - [理由]
  3位：[タイトル] - 強度__ - [理由]

最も再現価値が高いフック：[フックタイプ名 + 具体的な再現方法]
```

---

## Phase 4：仮説検証レビュー（15分相当）

`~/Brain/YouTube/scripts/` 内の直近3ファイルを読み込む。
各ファイルのフロントマター（`verdict` フィールド）を確認し、以下を判定する：

```
仮説検証状況：
  [ファイル名1]
    仮説：[hypothesis フィールドの内容]
    判定日：[verdict_date]
    現在のverdict：[未判定/合格/棄却]
    → 判定日を過ぎているが「未判定」のものは「要判定」としてフラグ

  [ファイル名2] …
```

同一フックタイプの記録本数を `~/Brain/YouTube/patterns/` から確認し、採用可否を出力する：

```
パターン採用状況：
  確定採用（2本以上）：[フックタイプ名] x [本数]
  仮説段階（1本）：[フックタイプ名]
  未記録：[フックタイプ名]
```

## 保存

上記4フェーズの結果を以下の構造で `~/Brain/YouTube/weekly/[YYYY-MM-DD]_週次リサーチ.md` に保存する：

```markdown
# 週次リサーチ [YYYY-MM-DD]
ジャンル：$ARGUMENTS

## 今週の外れ値候補
[Phase 1の結果]

## サムネイル感情分析
[Phase 2の結果]
### 今週のサムネイルトレンド
[共通要素の要約]

## フック感情強度ランキング
[Phase 3のランキング出力]

## 仮説検証レビュー
[Phase 4の結果]

## 前週との差分
### 新トレンド（今週初めて確認）
- [新しく出てきた動画パターン・フック・感情スタイル]

### 消えたトレンド（先週はあったが今週ない）
- [先週の週次リサーチにあったが今週見られなかった要素]

### 今週の最優先実験仮説
「[Phase 3で最も強度が高かったフックを使うと、[KPI]が改善する]」
```

前週のファイルが存在する場合は必ず読み込んで「差分」セクションを完成させること。
前週のファイルが存在しない場合は「差分：初回のため比較なし」と記載する。

保存完了後、「週次リサーチを保存しました：[ファイルパス]」と報告すること。
