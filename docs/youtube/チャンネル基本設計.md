# チャンネル基本設計

> 最終更新: 会話ヒアリング・申し送りプロンプト・レビュー反映を要約した設計書。  
> 正式チャンネル名と3ヶ月数値目標は未確定。

## 【チャンネル基本設計】

### 1. チャンネル名・コンセプト（一言で）

- **チャンネル名:** 未確定。方向性は **キャラ属性が名前から伝わる群像型**（1キャラ主役型か対比型かは最終判断待ち）。
- **命名で避けるもの:** 「犬飯」（美味しそうに見えないイメージ）、「男子」、海外で悪い連想の語（例: テロ）、**名前の先頭に「AI」**、猫連想が強い「肉球」中心の表現。
- **コンセプト（一言）:** AI生成の個性派犬キャラが、キッチンと日常を舞台に掛け合いコメディで再現し、時に社会の「あるある」を犬目線で風刺する。

### 2. ターゲット視聴者（年齢・属性・悩み）

- **年齢:** 中心は20〜40代（30〜40代の副業・生産性・AI活用層と、犬好き女性層の両取り）。
- **属性:** ペット飼育者、未飼育の犬好き、SNSでショート・エンタメを消費する層。性別でネタを寄せない。
- **悩み・欲求:** 日常あるある（職場・SNS・消費・飼い主あるあるのミックス）、短時間で笑える・癒やされる、AIっぽくない人間味、キャラに愛着を持ちたい。

### 3. 競合チャンネルと差別化するポイント

- **参考・ベンチマーク:** `Owlkitty`（最優先）、`ええとこのねこツナちゃん`、`neko neko project`。
- **差別化:**
  - 単体ペット実写ではなく、複数犬キャラの掛け合いIP（可愛い／ブサかわ／キザ／ギャル／怠け／小学生など）。
  - 女子高生流行語を犬台詞に翻訳した口調（AI説明口調を避ける）。
  - 背景の暴走はしない。AIの仕掛けは包丁・影・水・カメラ・字幕などに限定。
  - 犬種で芯を作り、血液型あるある等は企画回だけ属性を上書き（ハイブリッド運用）。
  - 品質目標は雑な量産ではなく映像の説得力（`Owlkitty`級を志向）。
  - 企画〜振り返りを Linear と Obsidian で型化し、単発バズではなく再現運用。

## 【コンテンツ設計】

### 4. 動画のジャンル・テーマ（複数可）

- **主軸:** AI犬キッチン・料理コメディ（男子ごはん文脈は取り込むが、「男子」はチャンネル名・表現に出さない）。
- **副軸:** 映画・アニメ・ドラマ・CMの雰囲気パロディ（アンパンマン／ジブリ／鬼滅など。著作権配慮で設定変換）。
- **シリーズ型:** 血液型・属性あるある、犬種キャラ固定の日常風刺、「開店前テスト」型（巨大包丁・初出勤ギャグ等）。
- **社会テーマ:** チャンネル安定までは日常マナー・職場文化・SNS作法まで。安定後に段階的に拡張し、必ずコミカルに処理。

### 5. 1本の動画尺の目安

- **本編:** 初月は8〜12分想定（データで Short 化も検討）。
- **構成:** 冒頭30秒のつかみ → 本題 → 次回・関連へのCTA（一般予告に頼らないエンド）。

### 6. 投稿頻度の目標

- **初月:** 週1本（テンプレ試運転・品質優先）。
- **安定期:** 週1〜2本（Linear の親 Issue とサブタスクで回す）。

### 7. 台本のトーン・話し方のスタイル

- **形式:** 複数キャラの対話・ボケツッコミが基本。
- **文体:** 1文60文字以内、話し言葉。専門用語は一言説明を添える。
- **トーン:** コメディ80％＋ほっこり20％。中辛風刺はコミカルに処理。
- **品質:** AIっぽい説明列挙は禁止。ユーモア最低3箇所。
- **演出:** 冒頭30秒は独自の仕掛け（無音サムネカット、小物だけの逆再生、非物理ギャグ等）。背景キッチンは基本固定。

## 【言語・表現ルール】

### 8. 必ず使うキーワード・フレーズ

- **コア口癖（毎本どれか1つ以上）:** `それな` / `ビジュ爆発` / `詰んだ（笑）` / `タイパ神`
- **サブ口癖（文脈で）:** `しごでき` / `〜しか勝たん` / `正直、それ` / `リピ確` / `ガチ勢`
- **構成語:** つかみ30秒・本題・CTA
- **キャラ軸:** 犬種の芯（例: 柴＝頑固）＋特集回の属性タグ

### 9. 絶対使わないNG表現

- **ブランド:** 上記「命名で避けるもの」に加え、ワン丼など犬飯連想の料理名をタイトル・サムネで乱用しない。
- **内容:** 実際の事件・災害のネタ化、個人・属性攻撃、過激・グロ・虐待連想、政治・宗教の直接対立、炎上釣り煽り、誇大・怪しい案件PR。
- **演出:** 背景の毎秒暴走（継続視聴低下のため不可）。
- **文体:** AIっぽい定型説明・箇条書き羅列の台詞。

### 10. タイトルのフォーマット

- 30文字以内、数字を入れる、ベネフィットを先頭。
- 例: `3秒で笑える初出勤、伝説の包丁がデカすぎた` / `見た目が上がる3つの道具だけ`

**SEO（申し送り）**

- 説明文500文字以内。最初の100文字にキーワード。
- タグ15個、検索ボリューム大→小の順。

**サムネ（申し送り）**

- テキスト10文字以内。犬キャラ＋インパクト文言。競合と一目で差別化。

## 【キャラクター・制作環境（補足）】

### レギュラー犬（初期案）

| 犬種 | 役割イメージ |
|------|----------------|
| トイプードル | おしゃれ・トレンド・「ビジュ爆発」担当 |
| ゴールデンレトリバー | 安心・共感まとめ・「それな」担当 |
| フレンチブルドッグ | ブサかわ・人間臭さ・風刺の主砲 |
| チワワ | ツッコミ・瞬発力・「タイパ神」担当 |

### キャラ運用ルール

- **通常回:** 犬種キャラ優先（例: 柴犬＝頑固）。
- **特集回（血液型あるある等）:** 属性タグ優先で演じ分け。
- **出演:** AI生成で制作。環境は MacBook（M5 Max クラス）中心、スマホは確認・投稿運用。

### 投稿言語

- Phase1: 日本語のみで育成。
- Phase3: チャンネル安定後、英語は別チャンネルで展開。

## 【目標数値】

### 14. 直近3ヶ月の目標（登録者・再生数など）

- **数値目標:** 未合意（初回投稿後の実績を見て設定）。
- **KPI優先順位（確定）:** 維持率 → CTR → 保存率。
- **進め方（案）:** 1ヶ月目はテンプレ1周と品質検証、2ヶ月目は勝ち型の再投稿、3ヶ月目は登録・保存率でシリーズ化判断。

### 15. 収益化の方針

- **バランス型・段階的:** Phase1 広告（維持率最優先）→ Phase2 スポンサー（怪しい案件NG）→ Phase3 犬キャラIP・グッズ。
