# 制作ワークフロー

YouTube チャンネル制作におけるツール分担と工程。Linear テンプレは [Linear運用テンプレート.md](../../Linear運用テンプレート.md) を参照。

## 役割分担

| 工程 | 担当 | 内容 |
|------|------|------|
| 企画 | Cursor（Claude） | ブレスト、競合調査、テーマ選定 |
| 台本 | Cursor | 8割生成（人間が残り2割を修正） |
| 台本レビュー | Codex（`orchestrate.sh`） | 外部ターミナルで実行。Obsidian に自動保存 |
| サムネ・図解 | Cursor | 画像AI用プロンプト、必要素材の生成 |
| SEO | Cursor | タイトル案・説明文・タグ |
| 動画編集 | 人間のみ | Cursor はタッチしない |
| アップロード | 人間のみ | |
| 振り返り | Obsidian 自動保存 → 人間追記 | Postmortem・KPI |

## フロー図

```
Linear: 親Issue作成（Idea）
    ↓
Cursor: 企画・台本・SEO・サムネプロンプト（8割）
    ↓
外部: ./orchestrate.sh "作った台本をレビューせよ: [台本内容]"
    ↓
Codex レビュー → Obsidian 保存
    ↓
Cursor: 修正・完成（2割）
    ↓
人間: 素材生成の最終調整・編集・アップロード
    ↓
Linear: Publish → Review（24h / 72h / 7d）→ Postmortem → BacklogLearnings
```

## Linear ステータス

`Idea` → `Script` → `Production` → `Publish` → `Review` → `BacklogLearnings`

親 Issue 配下サブタスク: Script / AssetGeneration / Edit / ThumbnailTitle / Publish / Postmortem / BacklogLearnings

## Obsidian

- **デイリーノート:** `scripts/daily_note.sh` が Vault の `Daily/` に生成（引き継ぎタスク、当日タスク、振り返り）。
- **台本レビュー・Postmortem:** Codex 連携後のレビュー結果、KPI、継続／停止する型を記録（Vault パスは実行環境依存）。

## KPI と改善

優先順位: **維持率 → CTR → 保存率**

維持率が基準未達のときは内容構成（冒頭・中盤密度・オチ）を先に改善し、CTR は次点。詳細閾値は Linear 運用テンプレ §4 を参照。
