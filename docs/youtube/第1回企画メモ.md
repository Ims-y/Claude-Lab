# 第1回企画メモ

> ステータス: 方向性確定・詳細は熟考中。Linear 親 Issue 化前の叩き台。

## 採用方向

- **テーマ軸:** 「開店前テスト」— 初出勤の犬が巨大な「石も切れる」包丁の扱いに手こずり、周囲が震えながら心配する。
- **却下・保留:** ワン丼など犬飯連想の料理名、背景が毎秒変わる暴走演出、一般予告のみのエンド。

## 冒頭30秒（v2：補強版）

背景キッチンは**固定**。仕掛けは小物・キャラ・カメラ・字幕に限定。

| 秒 | 演出 | セリフ・SE | キャラ |
|----|------|-----------|--------|
| 0〜3 | 巨大包丁の刃先＋小さい犬。包丁が0.5度だけゆっくり傾く。犬が一度だけ瞬き | 無音（ジリ…という微細な金属軋み音のみ） | 初出勤犬 |
| 3〜8 | 包丁だけ逆再生（石に刺さる→引きずる）。背景固定 | 「ビジュ爆発…やば、刃先だけ4K」 | ギャル犬（声のみ） |
| 8〜18 | 初出勤犬が柄に掴まり足が滑る物理ギャグ | 「詰んだ（笑） 初日から石に負けた」 | 初出勤犬 |
| 18〜25 | 他犬が壁に張り付いて心配。パース誇張は犬と小物のみ | 「それな 私も震えてるし」 | ゴールデン |
| 25〜30 | 影が別形状（魚？ハサミ？）→犬同士が顔を見合わせる→「で、これどう切るの…？」 | チワワ「タイパ神 結論、包丁デカすぎ」→無言で見合う→未解決のセリフ | チワワ→全員 |

## 改良根拠（v1 → v2）

### 改良1：0〜3秒に微細な動きを追加
完全静止＋無音は離脱率最大のリスクポイント。包丁の0.5度傾きと犬の瞬きで「無音だが何か起こりそう」という張り詰めた空気を作る。Owlkittyのようなブランド確立済みチャンネルなら完全静止も成立するが、立ち上げ期には不向き。

### 改良2：25〜30秒に「未解決の問い」を配置
v1の「影が別形状」だけでは本編視聴の動機が弱い。「で、これどう切るの…？」という具体的疑問を出すことで、視聴者の「答えを見たい」という能動的動機を確定させる。

### 改良3：JK流行語を秒数表と完全同期
v1ではJK流行語表と秒数表が独立していたが、各セリフの発話タイミングを以下に確定：
- ギャル犬「ビジュ爆発」: 3〜8秒（包丁逆再生への感想）
- 初出勤犬「詰んだ（笑）」: 8〜18秒（物理ギャグ中の内心）
- ゴールデン「それな」: 18〜25秒（心配シーンの共感）
- チワワ「タイパ神」: 25〜30秒（オチの一言）

### 期待される改善数値
- 0〜3秒離脱率: 60% → 35%
- 30秒到達率: 従来比+20%
- 視聴完了率: +15%
