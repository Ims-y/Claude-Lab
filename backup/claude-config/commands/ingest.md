# ingest コマンド

## 役割
`.raw/`フォルダ内のファイルをナレッジネットワークに組み込む。

## 実行手順

### 引数あり（例：`ingest 論文名.pdf`）
指定ファイルのみ処理。

### 引数なし or `ingest all`
`.raw/`内の全ファイルを処理。

## AIのアクション（各ファイルに対して）
1. ファイルを読み込み、内容を把握
2. 以下の構成で`03_Resources/`にMarkdownファイルを作成：
   - ファイル名: 日本語の直感的な名前（M.D_内容.md形式）
   - `## 要約`（3〜5行）
   - `## キーコンセプト`（箇条書き）
   - `## 既存ノートとの関連`（[[Wikilink]]形式でリンク）
   - `## 原文参照`（.raw/ファイルへのリンク）
3. `wiki/index.md`に新規ページを追記
4. `wiki/hot.md`の作業履歴を更新
5. 処理済みファイルを`.raw/processed/`に移動
